This workshop assessment focuses on Responsive Web Development using Tailwind CSS
through the reconstruction of the GoStartup landing page template in a fully
offline environment. Within 120 minutes, participants are required to demonstrate
their ability to apply the mobile-first development approach by designing key 
sections including a 90% width hero image layout, a three-tier pricing section
with a highlighted “Basic” plan, and a clean, semantic website structure using
proper HTML tags and Tailwind utility classes only. The goal is to evaluate layout
accuracy, responsiveness across screen sizes, deployment readiness without external
CDN usage, and overall code cleanliness and organization.
